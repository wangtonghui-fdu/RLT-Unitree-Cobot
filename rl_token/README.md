# RL token 阶段一

`rl_token.py` 是模块本身，文件开头的说明写了完整设计。要点：

- 输入：VLA 最后一层的前缀隐状态（三路图像、语言、对齐查询 token），先截断梯度。
- 2 层编码器加查询 token 读出 2048 维 RL token；2 层因果解码器只靠它重建前缀，上下文 90% 被遮掉。
- 独立的 AdamW、梯度裁剪和随机数流，不影响 VLA 主线训练。

| 文件 | 作用 |
|---|---|
| `rl_token.py` | 模块、训练步骤、存档与诊断量 |
| `patch_ppu_rlt.py` | 把模块接进 LingBot-VLA v2 官方训练循环的补丁（也含在 torch 2.6 上编译所需的几处修复）。补丁第 1 项要从我们另一份代码副本拷两个视频解码文件，这里没有附带，用官方解码路径时可跳过 |
| `unit_rng.py`、`unit_rlt.py` | 单元测试：模块不改变全局随机数流；前向和存取正常 |
| `smoke_chain.sh` | 冒烟链：开模块训 20 步存档 → 续训 → 关模块对照 |
| `compare_tb.py` | 逐步比较两次训练的标量，检查是否逐位相同 |

开关：环境变量 `LINGBOT_RLT=1`。验证结果：开和关各跑一遍，前 10 步主线的损失和梯度范数逐位相同。

阶段二（在 RL token 上做演员-评论家在线强化学习）还没有实现。
