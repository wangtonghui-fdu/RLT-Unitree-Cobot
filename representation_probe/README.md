# 表征诊断

问题：插入需要毫米级相对位置，RL token 和 VLA 的各路 token 里有没有这个信息？

| 文件 | 作用 |
|---|---|
| `fe_rlt.py` | 只跑 VLA 前缀，导出 RL token、各相机最后一层 token、视觉塔 token |
| `probe.py` | 岭回归 / 小网络 / 图块注意力探针，按示教分 5 折 |
| `px_extract.py`、`px_probe.py` | 像素上限对照：直接在原图上训练视觉塔或 CNN |

标签不需要人工标注：用正运动学算右手工具点相对"插入完成时刻"位姿的偏移。

结论（Cobot Magic 真机 100 条示教，插入前最后 30 毫米）：

- RL token 的读出精度（中位 8.2 毫米）和它的输入（右腕相机 token，8.3 毫米）一样，没有丢几何信息。
- 腕部相机比头部相机好 1.5 到 3 毫米；提高分辨率没有帮助。
- 约 100 条真机示教加事后标签分辨不了毫米级：模型能判断偏差方向，幅度只预测出三到七成。毫米级的比较需要带真值的仿真数据。
